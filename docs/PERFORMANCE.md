# 网络压力与性能测试

2026-10-02，WSL → 配置的远端主机，任务全部在外部配置指定的远端 tmux 会话中独立运行。只在专用 `/tmp/ssh4codex-*` 目录执行合成任务，没有运行科研分析。结果是这次链路上的测量，不是所有网络上的速度保证。

## 方法

基线为 v0.1.0；改进版为 v0.2.0。Python 标准库构建只监听 loopback 的 TCP 桥，单独代理测试连接的 SSH 密文；不改全机网络、tc、iptables、其它 SSH master 或用户 tmux 窗口。

延迟条件在每次转发的数据块上加 100 ms，抖动条件加 100 ± 75 ms。它模拟数据流延迟与波动，不是精确的包级 RTT/随机丢包仿真。故障测试包含关闭专用连接、暂时不转发数据，以及远端已开始任务后丢弃响应。前后测量先后进行，实际 WAN 也会抖动。

## 实际结果

| 场景 | 基线/逐个请求 | 改进/批量请求 | 说明 |
|---|---:|---:|---|
| 延迟链路下载 24 个小文件 | 25.474 s | 1.064 s | 25 次 SSH 请求合并为 1 次，约 24 倍 |
| 延迟链路查询 16 个完成任务 | 19.888 s | 1.258 s | 同一轮测试的逐个查询 vs status-many，约 16 倍 |
| 8 MiB 可压缩文件往返 | 213.428 s | 3.786 s | 重复 0..255 字节，SSH 压缩收益大；不代表 PNG/qs/随机数据 |
| 连接完全无响应至报错 | 20.004 s | 11.045 s | 改进测试设置 rpc_timeout=3、connect_timeout=8；不是默认超时 |
| 48 任务 / 8 路并发 | 12.374 jobs/s | 13.304 jobs/s | 全部成功，变化较小且受 WAN 抖动影响 |
| 96 任务 / 32 路并发 | — | 96/96 成功，11.313 s | 短任务；未据此承诺任意服务器能支持 32 路 |

单次查询并未表现出稳定加速：无人工延迟的 p50 从 0.3254 s 变为 0.4897 s，有延迟时 p50 从 1.2844 s 变为 1.2862 s。主要收益来自合并请求和减少可压缩数据的传输量，不是换了一套更快的 SSH 加密协议。

## 稳定性

- 最终压力测试 11 个场景全部通过：延迟/抖动、48 并发任务、24 次同 ID 请求只执行一次、16 任务批量查询、5 次断线重连、提交后丢失响应、读请求中断、连接黑洞与恢复、小文件批量下载、下载连接中断、8 MiB 往返。
- 已开始的任务在连接关闭后继续执行；查询后用相同 ID/原请求恢复，只读已有状态，没有重复写入副作用。
- 查询和下载的网络重试最多一次，绕过无响应的 master；任务提交、取消和上传不自动重放。认证、主机身份、校验错误不重试。
- 多文件下载只在全部文件和 SSH 退出码验证后发布；哈希错误、路径异常或中断清理暂存文件，已有目标保留。用编号的 tar 成员传输，不解压远端路径。
- 26 项单元测试通过，包括重试上限、提交/上传响应丢失、并发任务绑定、完成时 manifest、哈希变化和异常归档路径。
- 原有 14 项实际服务器验收全部通过，包含中文日志、R tidy 环境 ggplot2/qs、上传下载和超时取消；官方 SDK MCP 实际调用通过，8 个工具可发现，批量状态也经实际协议检查。

## 真实发现与调优

初次调优给握手只留 3 秒，真实网络波动中出现 banner exchange 超时，一轮压力测试失败（保留在 stress_intermediate.json）。没有将这轮算作通过。最终保留 8 秒建连预算，安装同一不可变 helper 可安全重试；提交恢复流程先查询原 ID，再按原请求获取已有结果。

本地任务登记原来直接改写 JSON。现使用锁和原子发布，跨线程/进程的相同 ID 不会读到半份记录，也不会并发绑定到两个服务器。

补充的 2 MiB 随机字节中途断线测试发现了第二个真实问题：OpenSSH 复用客户端在数据截断时可能返回退出码 0，原实现将截断误判为格式错误而没有重试。已根据归档声明长度识别截断并安全重试，查询的截断 JSON 也得到同样处理；校验错误仍不重试。

## 中途截断的最终实测

额外两项测试均通过：

- 不可压缩文件中断记录（原始记录保存在外部私有报告目录）：2 MiB os.urandom 数据，已在本地暂存 1 MiB 时断开；一次重试后完整恢复，SHA256 一致，3.742 秒，无暂存残留。
- 大段状态响应中断记录（原始记录保存在外部私有报告目录）：1 MiB 日志查询，桥已转发约 65 KiB 时断开；共两次 RPC，完整响应恢复，2.544 秒。

首次文件截断失败与修复记录（原始记录保存在外部私有报告目录） 保留。以上均是下载/查询恢复；不能据此自动重放任务或上传，也不是断点续传。
