# ssh4codex

面向 coding agent 的 SSH / tmux 连接器：持久任务、断线接回、增量日志、校验传输及 MCP。

[下载 Release](https://github.com/Vinnish-A/ssh4codex/releases/latest)。Linux x86_64 / WSL，glibc 2.35+；内含 Python、OpenSSH 和 MCP SDK，解压即用。

```bash
curl -fsSL https://raw.githubusercontent.com/Vinnish-A/ssh4codex/main/install.sh | bash
```
